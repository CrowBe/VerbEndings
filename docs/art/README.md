# Art Reference Library

This directory contains the approved visual evidence used to brief, reconstruct, and review VerbEndings assets. [`CONTEXT.md`](../../CONTEXT.md) governs domain language, [`WORLD_DESIGN.md`](../WORLD_DESIGN.md) governs visual and spatial rules, and [`VISUAL_ASSET_PIPELINE.md`](../VISUAL_ASSET_PIPELINE.md) governs production boundaries.

[`REFERENCE_ASSET_MAP.md`](REFERENCE_ASSET_MAP.md) records the current reference coverage for the complete 3D asset portfolio. A generated image, video, or mesh is not a runtime asset unless its focused brief and evidence explicitly say that it satisfies the Production readiness contract.

Current retained packages:

- [`subjects/shared_subject/`](subjects/shared_subject/) — approved shared Subject anatomy, exact Meshy inputs, controlled renders, and a high-detail production-source mesh;
- [`intro/flux/`](intro/flux/) — non-runtime motion, audio, composition, and facility-context evidence from the third-pass FLUX intro;
- [`material_dispenser/`](material_dispenser/) — the integrated production-preparation Material Dispenser and its controlled renders; and
- [`material_dispenser_comparison/`](material_dispenser_comparison/) — the controlled concept-to-proxy comparison that establishes the hard-surface reconstruction route.

Reference assets remain subordinate to the written contracts. Labels, colours, layouts, or machinery visible in context evidence do not become canonical merely because they appear in generated media.
