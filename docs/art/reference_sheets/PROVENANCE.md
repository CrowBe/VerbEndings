# Generated Reference-Sheet Provenance

## Role And Disposition

The suite provides retained visual-development evidence for every focused sheet gap recorded by [`REFERENCE_ASSET_MAP.md`](../REFERENCE_ASSET_MAP.md). The images remain review candidates rather than approved production sources. Written canon and implemented greybox contracts remain authoritative.

## Generation Method

- Tool path: built-in OpenAI image generation.
- Use case: `stylized-concept` for new sheets and `precise-object-edit` for bounded corrections.
- Generation date: 13 August 2026, Australia/Sydney.
- Output: RGB PNG files retained directly under this directory.
- Shared direction: rounded simplified stylised PBR; clinical, buoyant, tactile, overconfident, and quietly uncanny; neutral studio or controlled environment presentation; large readable physical relationships; bounded emissions; no watermark.
- Runtime disposition: none of the outputs is imported by Godot or treated as runtime geometry.

The generation set uses these retained project references according to family:

- the written requirements in `CONTEXT.md`, `docs/WORLD_DESIGN.md`, and `docs/art/REFERENCE_ASSET_MAP.md`.

Each input image serves as a visual reference. No existing source image is overwritten.

## Prompt Set

[`PROMPTS.md`](PROMPTS.md) defines the final shared prompt scaffold, every family-specific prompt delta, and the retained-output constraints. Those elements together are the final prompt set used for the retained outputs.

## Retained-Output Invariants

The retained outputs satisfy these visual-review invariants:

- the complete Compound has one Test Floor, one elevated annular Assignment Deck, and three Laboratory territories;
- the Drop/Recall sheet has a physical open-air Drop and an explicit three-bank, 24-socket layout;
- reconstruction inputs exclude captions, measurement labels, transition arrows, Verb jacket markings, and barcodes; the Subject identity sheet retains its intentional diegetic number tile;
- the Applied Attrition composition is one wedge-shaped Laboratory territory rather than a complete chamber;
- the breakable Material housing has a silhouette distinct from the established Material Dispenser;
- the Residual Adverb overlay uses the canonical worn Residual;
- Material resting and absorption forms resemble neither miniature actors nor human anatomy;
- event overlays use physical shutters, warning vanes, access states, power changes, and restrained haze rather than energy walls; and
- Material Dispenser state coverage preserves its existing base form while changing only iris position and powered emission.

Every retained image has visual inspection for subject, style, composition, and the relevant written invariants. Image-generation consistency does not establish metric accuracy, topology, rig suitability, collision, or runtime readiness.
