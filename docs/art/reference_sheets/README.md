# Generated Reference Sheets

This package provides focused visual-development coverage for every asset family in [`REFERENCE_ASSET_MAP.md`](../REFERENCE_ASSET_MAP.md). It contains 47 generated sheets. Together with the retained shared Subject turnaround, they cover all 48 rows in the map.

These images are candidate modelling and review inputs. They do not by themselves promote an asset to Production Source, Proxy, Production, or Polish. [`CONTEXT.md`](../../../CONTEXT.md), [`WORLD_DESIGN.md`](../../WORLD_DESIGN.md), the map's written requirements, and focused production briefs override any ambiguous or conflicting generated detail.

The sheets use neutral presentation, complete silhouettes, clean cells, large physical relationships, and the established facility palette. Text and loose presentation effects are excluded from the retained outputs wherever they would contaminate reconstruction input. Generated metre relationships remain visual guidance until a focused brief fixes exact dimensions, origin, facing, collision owner, and runtime target.

## Directory Roles

- [`shared/`](shared/) establishes palette, materials, state readability, scale, detail density, and physical Semantic Engine interface language.
- [`actors/`](actors/) establishes identity, temporary grammar, animation keys, character construction, Residual ancestry, and Material forms.
- [`compound/`](compound/) establishes topology, hub infrastructure, routes, transport, shell construction, and reusable kit pieces.
- [`applied_attrition/`](applied_attrition/) covers the complete Laboratory and its dominant supply and traversal apparatus.
- [`competitive_stress/`](competitive_stress/) covers the complete Laboratory and its measurement, displacement, and shelter apparatus.
- [`adaptive_containment/`](adaptive_containment/) covers the complete Laboratory, physical hostile-entry infrastructure, containment props, and concealed evidence.
- [`facility_state/`](facility_state/) establishes the shared persistent-state and Collapse treatment across families.

[`PROMPTS.md`](PROMPTS.md) records the final prompt set, and [`PROVENANCE.md`](PROVENANCE.md) records generation method, reference inputs, retained-output invariants, and disposition.

## Use Boundary

- Use these sheets to settle silhouette, part separation, material boundaries, physical state changes, and cross-family visual consistency.
- Do not infer exact dimensions from an image where the written map, world design, greybox, or a focused brief provides them.
- Do not reconstruct text, incidental tiny markings, extra fixtures, or ambiguous geometry introduced by generation.
- Actor state and effect sheets guide rig, material, and animation planning; they are not animation clips or runtime VFX.
- Environment composition sheets guide spatial and sightline review; the implemented greybox remains authoritative for collision and navigation.
- No file in this directory is referenced by a gameplay scene or placed under `assets/exports/`.
